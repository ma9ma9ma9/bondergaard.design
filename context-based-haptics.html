Overview

A kitchen knob might control temperature in one moment and a timer in the next. Should it feel the same for both?

At Bosch and Thermador, I built a haptic knob prototype to explore how tactile feedback can change with the interface. I call this context-based haptics: the knob adapts its feel to the setting the user is adjusting. The idea is to use the same physical control across different appliances, while giving each interaction the feedback it needs.

A boundary you can feel

For a temperature setting, the knob can create a stop at the end of the available range. The resistance gives the user a physical indication that they have reached the limit.

Different steps for different values

For a timer, stronger detents could mark the hours, while smaller detents mark the minutes. The aim is to make the difference between larger and smaller adjustments something the user can feel.

Building the feel

I built the prototype with an encoder and a small gimbal motor. The encoder tracks the knob’s rotation, and the motor provides the resistance and detents. This gives me a working control for exploring how the feedback feels alongside the interface.

The prototype was inspired by Scott Bezek’s SmartKnob project.
